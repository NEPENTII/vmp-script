# ![Preview](https://vmp.ir/img/VMP.png)

A collection of lightweight and optimized scripts for VMP servers, including a dedicated Server API.

Developed and maintained by **NEPENTII**.

## Features

- Multiple VMP scripts
- Dedicated Server API
- Lightweight and optimized
- Easy configuration
- Server-side validation
- Designed for VMP servers

## Server API

This repository includes a dedicated Server API for communication between the VMP server and external applications.

The API can be used for integrations such as:

- Web panels
- Websites
- Player data
- Server status
- Authentication
- Server statistics
